How This Compares to Excel & xlsx.js

This page provides the browser-side equivalent of Excel's Tabular PivotTable engine. In native Excel, a PivotTable is not just a standard grid—it operates off a decoupled pivotCacheDefinition and pivotCacheRecords part in OpenXML.

1. In-Workbook (Static XLSX Snapshot)

When an .xlsx is saved, Excel writes out pre-calculated text cells into the worksheet XML (sheet1.xml). In xlsx.js / viewer.js, that snapshot is drawn faithfully with fonts, merges, and number formats, but is not sliceable.

2. Browser Dynamic Engine (This Page)

This engine takes multi-dimensional records (like those recovered by xlsxKit.pivotRecords), builds an internal aggregation matrix, and generates clean HTML hierarchy rows with collapsible tree nodes, intermediate subtotals, and accounting formats.

Key Formatting Semantics Implemented:

  • Accounting Format: Uses $#,##0;($#,##0);- where negative variances receive accounting parentheses and zero values render as clean hyphens.
  • Row Hierarchy Spans: Primary row categories use HTML rowspan so category blocks anchor their children without label duplication down the spine.
  • Foldable Branch State: Clicking [-] / [+] toggles the subtree visibility and replaces child rows with the rolled-up subtotal.
  • Bi-Directional Data Bars: Calculates relative positive/negative bar widths originating from a 50% centerline for quick variance diagnosis.
