# Tools

`?view=tools` (`lib/alpineComponents/tools.js`) is a curated gallery of utility
pages, drawn with the pages card. [tools.csv](../tools.csv) is a crosswalk over
[pages/pages.csv](../../pages/pages.csv): each row names a page path and an icon,
and the title and note come from the page's own `pages.csv` row. Add a tool by
adding a row. A cross-repo or off-default entry renders through toss-render
`#gh=`. The hub is public, so the view needs no token.
