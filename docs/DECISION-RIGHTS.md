# Decision rights

Advance the work as far as sound judgment permits ([Be bold](https://mehrlander.github.io/web-tools/app/?view=map&tab=policy&h=bold)).

## The session decides

- Anything that can be undone cheaply later (a two-way door).
- Where an item goes in an existing classification.

## The owner decides

- A matter that turns on what the owner wants, such as a goal, a priority or a question of taste.
- A new or changed classification that other work reads: what it sorts by, its categories, or their names. Other work reads a classification once it appears in a registry column, a file name other files link to, or a term in a document sessions read.

When work needs a new classification or category before the owner has decided on it, keep it cheap to undo:

- Derive the new classification or category in code rather than store it.
- Keep it in the repository whose work reads it.
- Say in the reply that the session coined it.
