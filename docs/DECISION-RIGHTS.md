# Decision rights

Advance the work as far as sound judgment permits ([h:bold](https://mehrlander.github.io/web-tools/app/?view=map&tab=policy&h=bold)), and bring the owner what only the owner can decide.

## The session decides

- Anything that can be undone cheaply later (a two-way door).
- Which existing category an item belongs in.

## The owner decides

Bring these to the owner:

- A matter that turns on what the owner wants, such as a goal, a priority or a question of taste.
- A new or changed classification that other work reads: what it sorts by, its categories, or their names. Other work reads a classification once it appears in a registry column, a file name that other files link to, or a term in a document sessions read. Its names are not cheap to undo, because every file that uses them must change.

When work needs a new category before the owner has answered, keep it cheap to undo: derive it in code rather than store it, keep it in the one repository that needs it, and say in the reply that the session coined it.
