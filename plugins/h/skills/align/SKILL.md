# Align now · `h:align`

Align names, text or structure that disagree with each other or with what is true as soon as you notice them. Do it in the same session, before the mismatch causes any confusion.

- Carry a rename to every place the name appears, including links to it in our own repos.
- Fix unclear or inconsistent wording where you meet it, including text held in code.
- When alignment cannot finish in this session, say so and make it the next step.

The caution in [web-tools CLAUDE.md](https://github.com/mehrlander/web-tools/blob/main/CLAUDE.md#where-the-rest-of-the-system-lives) against improvements addressing hypothetical problems is meant for new guards, rules and channels. A check added after a session errs once is one such guard.
