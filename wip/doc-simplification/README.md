# Documentation simplification fan-out, 2026-09-27

Working folder for a one-off fan-out. Thirteen readers each wrote one file here: eleven cover one slice of the estate (web-tools, home, shortcut-tools, web-tools-private), and two cover a cross-repo lens. Each proposal is then checked by an adversarial skeptic (`*.verdict.md`), and a synthesis ranks the survivors (`REPORT.md`).

The folder is committed as the work lands so a session limit cannot lose it. It is not a living document: once the proposals are acted on or declined, delete the folder.
