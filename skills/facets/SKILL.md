# Facets

## Premise

A set can be organized by finding the properties that define its members and set them apart.

Each member has properties. A property is well defined when a reader can state a member's value for it and point to where the value comes from. A facet is a well-defined property asked of every member of a set.

The question for a set is which well-defined properties each member has, and where the members differ in interesting ways.

## Key insights

Suggested by two tests of the belief, on [category words](https://github.com/mehrlander/web-tools/blob/main/research/category-mapping/README.md) and on [the parts of a page](https://github.com/mehrlander/web-tools/blob/main/research/category-mapping/2026-11-10-parts/README.md). None is settled.

- **A property every member shares sorts nothing.**
- **Two properties that divide the set the same way are one property, or the set is too small to separate them.**
- **Some values describe a member's place and belong with what holds the member.** In the second test, one reader recorded such a value as a property of each member, and the other as a rule about what holds it.
- **A reader given only the question reached the same main findings as readers given a procedure.**
