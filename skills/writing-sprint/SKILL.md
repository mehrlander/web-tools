# Writing Sprint

Punch up a text: restate its core insight using a move, a technique shown in a named writer's passage. Borrow the technique, not the writer's mannerisms or an assistant's stock phrasing.

1. State the text's core insight in one sentence.
2. Choose two or three moves that fit the insight from home's [`projects/skill-lab/moves.md`](https://github.com/mehrlander/home/blob/main/projects/skill-lab/moves.md). To channel a writer the file lacks, add their passage there first, following the file's rules for adding a passage.
3. Rewrite the insight sentence once per move, dropping what that move's entry says to leave behind. Show the trials, one line each, then keep the strongest and say why.
4. Rebuild the text from that sentence, opening the new version with it and adding only the context a reader needs to follow it, as [The Art of Arriving Together](https://github.com/mehrlander/home/blob/main/chron/2026/03/2026-03-10-the-art-of-arriving-together.md) describes. To rebuild a prompt, [inspire-excellence](../inspire-excellence/SKILL.md) has forms for one.
