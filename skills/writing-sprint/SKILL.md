# Writing Sprint

To make a text stronger, borrow a technique from a passage that shows it, not from a writer's name.

The techniques, called moves, are filed in home's [`moves.md`](https://github.com/mehrlander/home/blob/main/projects/skill-lab/moves.md), each with the passages that show it.

## Steps

1. Choose three moves that suit the text, and read their passages.
2. Write one version of the text with each move.
3. Keep the version that serves its reader best.
4. Check that the kept version still says what the text had to say, and shows none of the habits the [`peeves`](../peeves/SKILL.md) list names.

For a punch-up, choose one move and write one version.
