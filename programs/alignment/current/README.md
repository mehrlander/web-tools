# Current-state maps

Each map in this folder says how one part of the estate (the owner's repositories and everything in them) fits together as it stands. A map is written in the present tense and corrected in place. It has no "as of" date. Its data sits beside it. A check re-derives every claim it measures.

Proposals that would change a mapped part go in [`future/`](../future/), apart from the map.
