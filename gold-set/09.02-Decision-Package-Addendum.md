**Cells the writer did not re-emit: 2.** 2 empty with a style that is the package default in every field, so nothing renders differently.

**Short of the kept sheets.** Hyperlinks 1 of 2; VML drawings (comment boxes) 0 of 1. That gap is the writer losing something the sheets still hold, not the sheets you dropped.

- **Hyperlinks.** The lossy one, measured across the OFM forms. The writer models a hyperlink as a property of a cell, so two links anchored on the same top-left cell collapse to one, and a link carrying only a location fragment (an in-workbook anchor) is dropped. Ordinary one-cell links to a URL survive.
- **Cell format records.** A workbook-wide table. It shrinks when a sheet goes because the writer prunes the records nothing uses, so this row measures the table and not the fidelity.
- **Defined names.** The writer emits every name workbook-global, so a sheet-local name keeps its reference and loses its scope. A name whose reference points at a dropped sheet is listed below.
- **Calc chain entries.** Dropped deliberately. It is a recalculation order cache whose every index moves when a sheet goes, so the workbook sets fullCalcOnLoad instead and Excel rebuilds it.
- **Printer settings.** Per sheet, and nothing carries it: the writer models no page setup binary and no graft claims it. The loss is invisible until someone prints.
